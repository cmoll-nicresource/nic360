# Editor news clipper

The standalone Manifest V3 extension lives in `tma-ext/`. It has a separate Git repository and pre-existing uncommitted changes, and is excluded from the website repository. Preserve that work; do not push it to an unrelated upstream. Reload the unpacked extension after updates; beta backend deployment alone does not update an installed copy.

Version 2.1.0 reads Open Graph/Twitter title, description and image metadata, Article JSON-LD (including graph nodes), explicit publication metadata and time elements. A social description is preferred as the initial draft excerpt; scraped article text is a fallback. `articles.socialPreview.description` and `.imageUrl` preserve the original preview separately, under the same full-content access rule as excerpts. Images remain external publisher URLs: the backend does not fetch them. Missing dates stay absent; invalid submitted dates return a useful 400 error rather than becoming the clipping date.

The popup shows an editable publication date, image URL, excerpt and existing location selector. Explicit article `contentLocation`, `locationCreated` and geographic metadata supply suggestions; publisher organization addresses are ignored. Geographic country codes can identify a country. Unknown subdivision codes, ambiguous names and unmatched locations remain for review. No taxonomy records are created. Subjects/products and final publication remain manual CMS tasks.

`GET /api/extension/locations` requires staff JWT authentication, paginates the existing location catalog, and includes ancestor labels. `POST /api/extension/articles` validates date, source/image URLs and selected location IDs, derives the source domain from the URL, strips common source tracking parameters and saves only a draft. Signed image query parameters are retained. Duplicate URL lookup includes drafts, and does not overwrite an existing record. Concurrent URL imports are not protected by a database uniqueness constraint; this remains a limitation.

Apply the additive, idempotent [schema update](../migration/extensionSocialPreview.sql) before deployment to an existing database; it adds optional preview columns to Articles and its version table. No old article, excerpt, index term or issue reference is altered.

Checks: CMS unit tests cover validation, permission boundaries, preserving the original preview, edited excerpts and duplicate URL handling. The browser suite exercises staff JWT login, catalog reads, a real PostgreSQL draft write/readback, date/location/preview persistence, duplicate detection, recent clips and preview privacy after synthetic publication. Seven standalone extension Chromium checks cover extraction and popup behavior with synthetic metadata and mocked Chrome APIs. These are controlled fixtures, not a guarantee of every publisher's markup or paywall behavior.
